# Hava Savunma Gözetimi İçin Derin Öğrenme ile İHA-Kuş Ayrımı

# PROJE ÖZETİ 

Küçük insansız hava araçlarının (İHA) görüntü tabanlı tespitinde en büyük
sorunlardan biri, özellikle uzak mesafedeki kuşların İHA sanılması (yanlış alarm)
sorunudur. Bu projede, havada uçan nesnelerin "İHA" ve "Kuş" olarak ayırt edildiği
ikili bir görüntü sınıflandırma problemi ele alınmaktadır. Odak noktaları:
yanlış alarm oranı ve modellerin farklı veri setlerine genelleme başarısıdır.
